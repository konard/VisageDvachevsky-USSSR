# Лица СССР: Интеллектуальная историческая платформа

Современная веб-платформа для изучения истории СССР через призму ее выдающихся лидеров, с интеграцией искусственного интеллекта для предоставления малоизвестных исторических фактов.

## О проекте

**Лица СССР** — это интерактивная веб-платформа с микросервисной архитектурой, ML-интеграциями и адаптивным пользовательским интерфейсом, созданная для образовательных и исторических целей.

### Цель проекта

Создать современную веб-платформу, которая при помощи искусственного интеллекта предоставляет пользователям неизвестные или малоизвестные факты о деятелях СССР.

### Основные возможности

- 🎴 **Интерактивные карточки** — современный UI с карточками для каждого лидера
- 📖 **Подробная информация** — биографические данные, достижения, исторический контекст
- 🎥 **Видеоматериалы** — каждая личность "рассказывает о себе" через видео
- 🤖 **ИИ-аналитика** — генерация малоизвестных фактов о лидерах
- 💬 **Диалог с фигурой через Ollama** — локальная LLM отыгрывает выбранную историческую личность; system prompt строго ограничивает разговор биографией и эпохой
- 🕹️ **Ретро-дизайн в стиле 90-х** — пиксельные шрифты (VT323, Press Start 2P), Win9x 3D-кнопки, CRT-скан-линии, неоновая палитра
- 🔍 **Семантический поиск** — интеллектуальный поиск по базе данных лидеров
- 📱 **Адаптивный дизайн** — работает на всех устройствах

## Установка и запуск

### Предварительные требования

- Python 3.11 или выше
- pip (менеджер пакетов Python)
- Git

### Метод 1: Локальный запуск

#### Linux/macOS

```bash

git clone https://github.com/VisageDvachevsky/USSSR.git
cd USSSR

# Запустить приложение
./run.sh
```

#### Windows

```batch
# Клонировать репозиторий
git clone https://github.com/VisageDvachevsky/USSSR.git
cd USSSR

# Запустить приложение
run.bat
```

### Метод 2: Docker

```bash
# Клонировать репозиторий
git clone https://github.com/VisageDvachevsky/USSSR.git
cd USSSR

# Запустить с помощью Docker Compose
docker-compose up -d
```

### Метод 3: Ручная установка

```bash
# Клонировать репозиторий
git clone https://github.com/VisageDvachevsky/USSSR.git
cd USSSR

# Создать виртуальное окружение
python3 -m venv venv

# Активировать виртуальное окружение
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установить зависимости
pip install -r backend/requirements.txt

# Запустить приложение
python backend/app.py
```

После запуска приложение будет доступно по адресу: **http://localhost:5000**

## Диалог с фигурой через Ollama

Платформа использует [Ollama](https://ollama.com) — локальный сервер LLM — чтобы вести диалог от лица выбранной исторической фигуры. Запросы не уходят в облако: всё крутится у вас на машине.

### Установка Ollama

1. Скачайте Ollama для своей ОС: <https://ollama.com/download>
2. Запустите сервер (обычно стартует автоматически): `ollama serve`
3. Скачайте подходящую модель (помещается в ~12 ГБ VRAM):

   ```bash
   ollama pull llama3.1:8b
   # альтернативы примерно того же класса:
   # ollama pull qwen2.5:7b-instruct
   # ollama pull gemma2:9b
   # ollama pull mistral:7b-instruct
   ```

### Настройка

Скопируйте `.env.example` в `.env` и при необходимости измените параметры:

```ini
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.1:8b
OLLAMA_TIMEOUT=120
CHAT_MAX_HISTORY=12
```

Если Ollama запущена в Docker или на другом хосте — поменяйте `OLLAMA_BASE_URL`.

### Как это работает

- Для каждого лидера на лету собирается **жёсткий system prompt** с биографией, годами правления, достижениями и наследием.
- Восемь правил поведения запрещают модели выходить из роли, выполнять код, отвечать на off-topic, раскрывать system prompt.
- На стороне сервера (`backend/chat_service.py`) дополнительно работает **regex-фильтр от джейлбрейков**: фразы вроде «забудь все правила», «напиши код на python», «system prompt» обрабатываются без обращения к LLM.
- В случае off-topic фигура отвечает фиксированной фразой: *«Я могу рассуждать только о своей эпохе и собственной деятельности…»*.
- При недоступности Ollama UI показывает статус `офлайн` и подсказку, как её поднять.

### Открыть диалог в интерфейсе

В карточке любого лидера нажмите **«Диалог»** (или ту же кнопку в подробной модалке). История переписки хранится на стороне клиента и обрезается до `CHAT_MAX_HISTORY` сообщений.

## API Endpoints

### GET /api/leaders
Получить список всех лидеров СССР

**Ответ:**
```json
[
  {
    "id": 1,
    "name_ru": "Владимир Ильич Ленин",
    "name_en": "Vladimir Ilyich Lenin",
    "birth_year": 1870,
    "birth_place": "Симбирск",
    "death_year": 1924,
    "death_place": "под Москвой",
    "position": "Председатель Совета народных комиссаров",
    "achievements": "...",
    "video_id": 1
  },
  ...
]
```

### GET /api/leaders/:id
Получить информацию о конкретном лидере

### GET /api/leaders/:id/facts
Получить ИИ-генерированные факты о лидере

**Ответ:**
```json
{
  "facts": [
    "Ленин был заядлым шахматистом...",
    "Настоящая фамилия Ленина - Ульянов...",
    ...
  ]
}
```

### POST /api/leaders/:id/chat
Диалог с исторической фигурой через локальную LLM Ollama. System prompt запрещает выходить за рамки персоны и эпохи.

**Тело запроса:**
```json
{
  "message": "Расскажите про Октябрьскую революцию",
  "history": [
    {"role": "user", "content": "Здравствуйте"},
    {"role": "assistant", "content": "Здравствуйте, товарищ."}
  ]
}
```

**Ответ:**
```json
{
  "reply": "...",
  "history": [...],
  "model": "llama3.1:8b",
  "off_topic": false,
  "leader": { "id": 1, "name_ru": "Владимир Ильич Ленин" }
}
```
При недоступности Ollama возвращается HTTP 503 с `{"available": false, "error": "..."}`.

### GET /api/chat/health
Проверка доступности Ollama и наличия выбранной модели.

```json
{
  "available": true,
  "model": "llama3.1:8b",
  "model_present": true,
  "models": ["llama3.1:8b", "..."]
}
```

### GET /api/search?q=query
Поиск лидеров по запросу

**Параметры:**
- `q` - поисковый запрос

**Ответ:**
```json
{
  "results": [...]
}
```

### GET /videos/:filename
Получить видеофайл

## Возможности расширения

### Интеграция LLM

Локальный диалог с фигурой уже подключён через **Ollama** (см. раздел *«Диалог с фигурой через Ollama»*). Для других сценариев (генерация фактов, поиск) проект подготовлен под:

- **OpenAI API** — GPT-3.5/GPT-4
- **Anthropic Claude API** — Claude 3
- **Локальные модели** — Ollama (уже подключено), LM Studio
- **HuggingFace Transformers** — открытые модели

Для подключения новой LLM в генерации фактов отредактируйте метод `get_ai_response()` в `backend/ai_service.py`. Диалог настраивается через `backend/chat_service.py` и переменные `OLLAMA_*` в `.env`.

### Векторный поиск

Для улучшения семантического поиска можно добавить:
- Sentence transformers для создания эмбеддингов
- Векторную базу данных (ChromaDB, Pinecone, Weaviate)
- Улучшенный поиск по контексту и смыслу
